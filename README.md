# Neon Maze — After Hours

A neon arcade maze game. Collect every energy core, avoid the roaming sentries, and reach the portal. Each sector generates a fresh maze.

## Play

Open [index.html](./index.html) in a modern browser, or visit the live GitHub Pages site once deployment finishes.

- Move with arrow keys or WASD.
- On touch screens, use the on-screen direction pad.
- Collect all cores to unlock the exit. You have three lives.

## About

Built with plain HTML, CSS, and JavaScript. No build step or external assets are required. Best times are saved in your browser when local storage is available.
